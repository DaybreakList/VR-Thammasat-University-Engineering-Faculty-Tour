# วิธีทดลอง Windows Prototype

1. ดาวน์โหลด ZIP จาก GitHub Releases และแตกไฟล์ทั้งหมด
2. เปิด `VR_TSE_Virtual_Tour.exe` จากโฟลเดอร์ที่แตกไฟล์
3. คลิกหน้าต่างเกมเพื่อให้รับ Keyboard/Mouse และดูปุ่มแนะนำของ XR Device Simulator
4. เลือกควบคุม Controller ก่อนใช้เมาส์ขยับ Ray จากนั้นใช้ Trigger ตามคำแนะนำบนหน้าจอ
   การควบคุม Headset อย่างเดียวจะยังไม่ทำให้ Controller ชี้หรือกดปุ่ม
5. กด START TOUR เพื่อปิดคำแนะนำครั้งแรก ใช้ HELP เพื่อเปิดอีกครั้ง
6. ใช้ Ray เลือก Hotspot เพื่อย้ายจุด ไม่ใช่เดินทะลุภาพด้วย WASD

ถ้าหน้าต่างไม่ตอบสนอง ให้ตรวจว่ามีการเลือก Controller และหน้าต่างเกมได้รับ Focus
หากจอดำหรือโปรแกรมปิดเอง ให้ส่ง Player.log พร้อมรุ่นการ์ดจอและอาการให้ทีม
ตำแหน่ง Log บน Windows อยู่ใต้ `%USERPROFILE%/AppData/LocalLow/VR TSE/VR TSE Virtual Tour`

## เส้นทางที่ควรทดลอง

```text
P09 ---- P08 ---- P07 (302) ---- P06
 |                               |
P10                             P05
 |                               |
P01 ---- P02 ---- P03 ---------- P04 (301)
HOME
```

- เดินครบ P01-P02-P03-P04-P05-P06-P07-P08-P09-P10-P01 แล้วลองย้อนกลับ
- เปิด MAP: ตำแหน่งสีเหลืองต้องตรงกับจุดที่อยู่
- เลือกห้อง 302 จาก HOME: ทางที่แนะนำควรผ่าน P10-P09-P08-P07
- เลือกห้อง 302 จาก P04: ทางที่แนะนำควรผ่าน P05-P06-P07
- ลองเปลี่ยนทางระหว่างนำทาง และตรวจว่าเส้นทางคำนวณจากจุดปัจจุบัน
- ลอง CANCEL ROUTE, HOME และเปิด/ปิด MAP, DESTINATIONS, HELP
- เข้าห้อง 301 จาก P04, ทดลอง Teleport แล้วออกกลับ P04
- กด Alt+F4 เพื่อปิดโปรแกรม

Prototype นี้ใช้ภาพจำลองและ UX/UI ทดลอง ภาพสถานที่จริงและหน้าตาสุดท้ายจะพัฒนาต่อ
Windows Player ใช้ทดลองบนคอม ส่วน Pico 4 ต้องติดตั้งและทดสอบ Android APK แยกต่างหาก
